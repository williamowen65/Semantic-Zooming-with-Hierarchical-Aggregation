# Notifications — Permissions and Ownership

## Purpose

Define who is allowed to receive, inspect, configure, or act on notification data.

## Questions

- A notification belongs to which user or users?
- Can moderators or administrators inspect another user's notifications, and under what circumstances?
- Which notification preferences can users control?
- Can users mute a Node, branch, relationship, person, or notification category?
- How do privacy rules affect notifications generated from private or restricted content?
- If a Node later becomes inaccessible, what should happen to old notifications that reference it?
- Which service identities are allowed to publish events or create delivery attempts?
