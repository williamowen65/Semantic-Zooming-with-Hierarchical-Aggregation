## Table of Contents

- [Purpose](#purpose)
- [Known Context](#known-context)

## Purpose

Plan users, identity, profiles, ownership, and the way Nodes are surfaced through a person's profile.

## Known Context

A user profile can expose multiple root Nodes. Root status is contextual rather than requiring a special RootNode class. Authentication and identity are expected to remain part of the main application layer.

## Questions to Explore

- What profile information is public versus private?
- How are root Nodes associated with profiles?
- Who owns a Node, and can ownership or stewardship change?
- How should anonymous or pseudonymous participation work, if allowed?
- Which profile actions require authentication or elevated permissions?
